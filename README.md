# English Intelligence Bot

A Telegram bot that delivers daily curated English learning packages for C1–C2 learners.

## Features

- **Daily English Intelligence Pack** — one expression, fully unpacked with definition, collocations, cultural references, native usage, contrast, and a mini task
- **7 Learning Modes** — General, Literary, Modern Native, Business, Cinematic, Intellectual, Music & Culture
- **Spaced Repetition** — saved expressions reviewed at 3, 7, and 21 days
- **Interactive buttons** — Save, I know this, More examples, Challenge me, Repeat later
- **Powered by Claude** — content generated by `claude-opus-4-7`

## Setup

### 1. Clone & install

```bash
git clone <repo>
cd engBOT
python -m venv venv
source venv/bin/activate
pip install -r requirements.txt
```

### 2. Configure environment

```bash
cp .env.example .env
```

Edit `.env`:

```
TELEGRAM_BOT_TOKEN=your_token_from_botfather
ANTHROPIC_API_KEY=your_anthropic_api_key
DAILY_HOUR=9
DAILY_MINUTE=0
TIMEZONE=Europe/London
```

### 3. Run

```bash
python main.py
```

## Bot Commands

| Command | Description |
|---------|-------------|
| `/start` | Register and see welcome message |
| `/today` | Get today's intelligence pack immediately |
| `/mode` | Switch learning mode |
| `/save` | Browse your saved expressions |
| `/review` | Check spaced repetition queue |
| `/pause` | Pause daily messages |
| `/resume` | Resume daily messages |
| `/help` | Show help |

## Architecture

```
engBOT/
├── main.py                        # Entry point, bot setup
├── bot/
│   ├── handlers/
│   │   ├── commands.py            # /start, /today, /mode, /save, etc.
│   │   └── callbacks.py           # Inline button handlers
│   ├── models/
│   │   └── database.py            # SQLAlchemy models + async engine
│   ├── services/
│   │   ├── content_generator.py   # Claude API calls
│   │   ├── formatter.py           # Telegram message formatting
│   │   ├── scheduler.py           # APScheduler daily jobs
│   │   └── user_service.py        # User & vocab CRUD
│   └── keyboards.py               # Inline keyboard builders
├── requirements.txt
└── .env.example
```

## Database Schema

- `users` — Telegram users with mode and daily settings
- `vocab_items` — Saved expressions per user
- `interactions` — User action log
- `review_schedules` — Spaced repetition schedule (3 / 7 / 21 days)
